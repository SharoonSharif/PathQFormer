# Submission checklist (IEEE JBHI, regular paper)

What is in this folder: `main.tex` / `main.pdf` (9 pages, IEEEtran journal, letter), `supplement.tex` / `supplement.pdf` (5 pages), `references.bib`, `figures/`, `cover_letter.md`. Build chain for both: `pdflatex && bibtex && pdflatex && pdflatex`. Both builds are clean (no errors, no undefined references, no overfull boxes > 10 pt). Main + supplement = 14 pages, the JBHI hard cap.

## Before uploading (author actions)

- [ ] **E-mail address.** Replace the literal placeholder `ADD-EMAIL` in the `\thanks{}` line of `main.tex` (line 32) and `supplement.tex` (line 50) with the address to print; JBHI expects an institutional address (bulldogs.aamu.edu) for the corresponding author.
- [ ] **Received date.** Replace `Manuscript received October XX, 2026` in both files with the submission date (or leave for the editorial office, which will overwrite it).
- [ ] **ORCID.** Register/confirm your ORCID and enter it in the ScholarOne author record; IEEE requires an ORCID for the corresponding author.
- [ ] **Institutional e-mail in ScholarOne.** Make the corresponding-author account use the institutional address, matching the one printed in the paper.
- [ ] **Overlength acknowledgement.** The main text is 9 pages: 1 page over the 8 free pages, so JBHI charges the mandatory overlength fee (currently USD 250 per page for pages 9–10). Tick the acknowledgement in the submission form. To avoid the charge the main text would have to lose about 1 page: candidates are Table IV (move the OS and 10-epoch rows to the supplement, keep the four DSS rows), the Site column and caption of Table I, the p-values in Sec. IV-A, Fig. 3 at single-column width (labels then print below 7 pt), and the Related Work paragraphs on learned queries and modality imbalance.
- [ ] **IEEE PDF eXpress.** Create the PDF eXpress account for JBHI (conference/journal ID from the submission site), upload `main.pdf`, and fix any font-embedding issue it reports (the current build embeds all fonts: Type 1 text fonts plus embedded TrueType fonts from the figures).
- [ ] **Supplementary upload.** Upload `supplement.pdf` as "Supplementary Material" (file designation: supplementary file for review), not as part of the main manuscript. Its tables are numbered S1–S14, figures S1–S3, sections S-I–S-VIII, matching every pointer in the main text.
- [ ] **Cover letter.** Paste the text of `cover_letter.md` into the cover-letter box (it contains the prior-submission (desk-reject) disclosure, AI-assistance disclosure, no-conflict and no-funding statements, data/code links and suggested reviewer areas).
- [ ] **Keywords.** Enter the Index Terms in the form: computational pathology; missing modality; model auditing; multimodal fusion; survival analysis; transcriptomics; whole-slide images.
- [ ] **GitHub release / Zenodo record.** The repository is public (checked 2026-10-05: MIT licence, tags v0.2.0-v0.2.2), the concept DOI 10.5281/zenodo.22900123 resolves (to record 22900124, version v0.2.1) and the Hugging Face checkpoint repository (sharoonsharif1/PathQFormer-checkpoints, 275 `best_checkpoint.pt` files) is public. Still to do: cut the release whose tag matches the Zenodo version, and update the Zenodo record's metadata, which currently lists the creator as "Thomas, Sharoon Sunny" (not the manuscript's author name) and describes the result as "+0.037 pooled over 75 paired folds (paired t p = 0.002)" and "180 five-fold runs", neither of which matches the manuscript's seed-averaged statistics or its run inventory.
- [ ] **Conflict / funding statements in the form.** Declare no conflicts and no funding (consistent with the Acknowledgment).
- [ ] **AI-use declaration in the form.** IEEE asks whether AI tools were used in writing; answer yes and cite the Acknowledgment sentence (Claude, Anthropic; drafting/editing and analysis code under the author's direction).
- [ ] **Final read of the PDF.** Check page 1 footnote (affiliation, e-mail), Fig. 1 (TikZ overview), Figs. 2–3 (full-width, labels ≥ 7 pt), Tables I–IV, and the Data and Code Availability links.
